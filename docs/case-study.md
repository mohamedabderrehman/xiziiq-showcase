# XIZI Iraq — Xiziiq

## Connecting visual project references to a quotation journey

XIZI Iraq presents an industrial business through a media-led website, technical document links, a project gallery and a contact route. The reviewed public interface lets visitors move from general solution information to project references and then describe a project in a quotation form.

The category controls change the visible project set. Arabic/English switching changes navigation and page content, including the contact form labels. This makes the language behavior part of the product journey rather than a separate translated homepage.

## Dynamic publishing with a private super admin panel

Mohamed Abderrehmane developed the website as a fully dynamic project with a super admin panel. The public showcase captures the deployed presentation while keeping application source, internal administration and implementation details private. Its GitHub repository is a case study and screenshot gallery, not executable application source.

The portfolio discusses media organization, multilingual navigation, project filtering and quotation intake. Company history, factory capacity and project installation figures belong to the business's presentation and are not claimed as the developer's results. The review did not submit the contact form or inspect private administration.
