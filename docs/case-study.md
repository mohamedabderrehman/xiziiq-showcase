# XIZI Iraq — Xiziiq

## An industrial website built around projects and product information

I built Xiziiq for XIZI Iraq as a fully dynamic website with Arabic and English interfaces. It brings together company information, elevator solutions, technical catalogues, project references and quotation requests. The project gallery helps visitors browse residential, commercial and panoramic work before moving to an inquiry.

## Language is part of the whole journey

The language switch carries through navigation, project content and contact-form labels. I wanted both languages to feel like complete ways to use the website. Project filters and technical catalogue links help visitors find relevant material, while the quotation form gives them a place to describe their project.

## Keeping administration behind the public experience

The website includes a super admin panel. I keep application source and internal administration private. This showcase shares the public website, its main workflows and selected screenshots.
