# XIZI Iraq — Xiziiq

Dynamic bilingual elevator website and project showcase

**Live website · Private application source · Documentation and screenshots only**

[Live website](https://xiziiq.com/) · [Portfolio case study](https://mohamed-abderrehmane-portfolio.hillock-factual9mupt.chatgpt.site/projects/xiziiq/)

Help visitors explore elevator and escalator solutions, technical catalogues and project references, then reach the quotation workflow in Arabic or English.

## Workflows and capabilities

Visitor explores the company and solution galleries → browses technical catalogue links → filters project references → switches Arabic/English presentation → opens a project inquiry form. The dynamic website includes a private super admin panel.

- Arabic and English presentation with an interactive language toggle
- Company, manufacturing, research and quality presentation with media galleries
- Technical PDF catalogue links for products and components
- Project gallery with residential, commercial and panoramic filters
- Quotation/contact form with project type and contact fields
- Fully dynamic website with a private super admin panel (developer-confirmed scope)

## Connecting visual project references to a quotation journey

XIZI Iraq presents an industrial business through a media-led website, technical document links, a project gallery and a contact route. The reviewed public interface lets visitors move from general solution information to project references and then describe a project in a quotation form.

The category controls change the visible project set. Arabic/English switching changes navigation and page content, including the contact form labels. This makes the language behavior part of the product journey rather than a separate translated homepage.

## Dynamic publishing with a private super admin panel

Mohamed Abderrehmane developed the website as a fully dynamic project with a super admin panel. The public showcase captures the deployed presentation while keeping application source, internal administration and implementation details private. Its GitHub repository is a case study and screenshot gallery, not executable application source.

The portfolio discusses media organization, multilingual navigation, project filtering and quotation intake. Company history, factory capacity and project installation figures belong to the business's presentation and are not claimed as the developer's results. The review did not submit the contact form or inspect private administration.

## Current review

Reviewed the live homepage, project gallery and contact page. Selecting the commercial category changed the visible project set, and the language toggle changed the Arabic interface to English. The quotation form was inspected with empty fields; it was not submitted. Private administration was not opened.

Application source and super admin interfaces remain private. Internal technology, database structure, administration permissions and business metrics are not disclosed or independently audited in this public case study.
