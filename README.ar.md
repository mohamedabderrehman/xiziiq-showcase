تمكين الزائر من استكشاف حلول المصاعد والسلالم والكتالوجات الفنية ومراجع المشاريع ثم الوصول لطلب عرض سعر بالعربية أو الإنجليزية.

## سير العمل والوظائف

يستكشف الزائر الشركة ومعارض الحلول وروابط الكتالوجات الفنية ثم يرشح مراجع المشاريع ويبدل العربية والإنجليزية ويفتح نموذج استفسار عن مشروع. يتضمن الموقع الديناميكي لوحة إدارة عليا خاصة.

- عرض بالعربية والإنجليزية مع زر تبديل تفاعلي
- عرض الشركة والتصنيع والبحث والجودة بمعارض وسائط
- روابط كتالوجات PDF فنية للمنتجات والمكونات
- معرض مشاريع بترشيح سكني وتجاري وبانورامي
- نموذج تواصل وعرض سعر بنوع المشروع وحقول الاتصال
- موقع ديناميكي بالكامل ولوحة إدارة عليا خاصة، وفق تأكيد المطور

## ربط مراجع المشاريع المرئية بطلب عرض سعر

يعرض XIZI Iraq شركة صناعية عبر موقع غني بالوسائط وروابط وثائق فنية ومعرض مشاريع وصفحة تواصل. يتيح العرض العام المشاهد الانتقال من معلومات الحلول إلى مراجع المشاريع ثم وصف مشروع في نموذج عرض سعر.

تغير عناصر الفئة مجموعة المشاريع الظاهرة. ويغير تبديل العربية والإنجليزية التنقل ومحتوى الصفحات، بما فيه عناوين نموذج التواصل. بذلك يصبح سلوك اللغة جزءاً من مسار المنتج وليس صفحة رئيسية مترجمة منفصلة فقط.

## نشر ديناميكي ولوحة إدارة عليا خاصة

طور محمد عبد الرحمن الموقع كمشروع ديناميكي بالكامل مع لوحة إدارة عليا. يوثق العرض العام المنتج المنشور مع إبقاء الشيفرة والإدارة والتفاصيل الداخلية خاصة. مستودع GitHub دراسة وصور، وليس شيفرة تطبيق قابلة للتشغيل.

يناقش المعرض تنظيم الوسائط والتنقل متعدد اللغات وترشيح المشاريع واستقبال عروض الأسعار. يخص تاريخ الشركة والطاقة الصناعية وأرقام التركيبات عرض الشركة، ولا تُنسب إلى نتائج المطور. لم تُرسل استمارة التواصل ولم تُفحص الإدارة الخاصة.

## الفحص الحالي

روجعت الرئيسية ومعرض المشاريع وصفحة التواصل. غيّر اختيار الفئة التجارية المشاريع الظاهرة وبدّل زر اللغة الواجهة العربية إلى الإنجليزية. فُحص نموذج عرض السعر بحقوله الفارغة ولم يُرسل، ولم تُفتح الإدارة الخاصة.

تبقى شيفرة التطبيق وواجهات الإدارة العليا خاصة. لا تكشف الدراسة التقنية الداخلية أو بنية القاعدة أو صلاحيات الإدارة أو أرقام الأعمال، ولا تدعي تدقيقها بصورة مستقلة.
